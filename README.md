# InRoom RQChat feed

Автообновляемый XML-фид для товарного справочника RQChat.

- Источник: `https://in-room.ru/marketplace/4675585.xml`
- Посадочная страница всех предложений: `https://in-room.rqch.ru/`
- Готовый XML: `https://lacriwo.github.io/inroom-rqchat-feed/inroom-rqchat.xml`
- Отдельный XML группы `grey`: `https://lacriwo.github.io/inroom-rqchat-feed/inroom-gray.xml`
- Обновление: один раз в сутки в 00:00 UTC (03:00 по Москве, 06:00 по Омску) через GitHub Actions и вручную через `workflow_dispatch`.

Преобразователь сохраняет основные данные предложений, заменяет `<url>` и добавляет плоские поля `offer_id`, `model`, `color`, `color_group`, `width`, `length`, `lift`, `available_value`, которые можно сопоставлять в RQChat. `offer_id` содержит стабильный ID варианта из исходного фида и используется как ключ ежедневного обновления. `color_group` сводит оттенки к группам для множественного выбора в чат-лендинге. Исходные повторяющиеся узлы `<param>` удаляются из конечного XML, чтобы импортёр RQChat не объединял их в одно поле.

`inroom-gray.xml` формируется тем же ежедневным процессом и содержит по одному предложению каждой модели из группы `grey`. Для стабильного выбора представителя скрипт предпочитает чистый цвет «темно-серый» и размер 120×200, а при их отсутствии выбирает доступный серый вариант по фиксированной сортировке. Основной `inroom-rqchat.xml` продолжает формироваться прежним скриптом без изменений.
